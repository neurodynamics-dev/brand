Site navigation on phones. Header stays; the button toggles between menu and close.
```jsx
<MobileSiteMenu links={['Início','Quem somos','Projetos','Contato']} footer={['Escola de Engenharia, UFMG','hello@neurodynamics.dev','Belo Horizonte, Brasil']} eyebrow="Iniciativa de P&D em saúde, sem fins lucrativos">{/* page content */}</MobileSiteMenu>
```
- Index numbers in Plex Mono (data); links in Archivo 600; active link in ink with a Synapse square, others Névoa.
- Footer lines and eyebrow are Archivo 600 uppercase, tracking .14em, never Plex Mono. No middle dots.
- Language switch is small and only appears once the menu is open; closed header is logo plus menu button.
