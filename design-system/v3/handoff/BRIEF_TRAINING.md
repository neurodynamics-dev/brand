# Brief: brand training for the NeuroDynamics team

## Goal
Teach the team (researchers, engineers, interns, admin staff, occasional designers) to apply the brand in the pieces they actually produce: presentations, documents, e-mails, social posts, internal tools. Participants should leave able to **pick the right template, mode and colour family**, and to spot the common mistakes.

Source of truth: `readme.md`. Examples: `templates/`, `guidelines/`.

## Format
- One 90-minute live session: 6 modules of about 12 minutes plus a 15-minute practical exercise.
- Deliverables:
  1. **Session deck** on `templates/brand-deck/` (operational mode, primary set).
  2. **One-page cheat sheet** (A4, printable) with the ten rules below.
  3. **Quiz** (10–12 multiple-choice questions, each answer with a one-line explanation).
  4. **Exercise kit**: three "broken" pieces to fix, with an answer key.
- Brazilian Portuguese, following every brand copy rule.

## Audience
Mostly non-designers. Teach decisions, not theory: "which template?", "which mode?", "can I use this colour here?". Use real examples from `templates/`.

## Modules

### 1. Por que a marca importa (10 min)
Who we are and how we sound (calm, professional, caring, direct). The neural metaphor behind the names. Two domains: Documents and Interface.

### 2. Os dois modos de tipografia (12 min)
- **Operacional** (default): Archivo titles, Instrument Sans text, Plex Mono only for codes and data.
- **Executivo** (certificates, formal reports, invitations, formal decks, business cards only): Instrument Serif headlines, Archivo Light text, never Plex Mono, never bold.
- Hierarchy without bold: lighter tone of the same family.
- Exercise: six pieces, participants name the mode.

### 3. Cor: os quatro conjuntos (15 min)
- Primary + neutral is the main composition; Synapse is a tiny spark (show the composition bar).
- Secondary families as auxiliaries, one per piece.
- Functional set only inside interfaces, for states.
- Only Cortex in glows, gradients, glass.
- Pairing rule for text on colour.
- Common mistakes: two families together, Synapse as a background, functional green used as brand green.

### 4. Logo e marcas (10 min)
Imagotipo vs square icon vs symbol vs white wave vs seal. Recolour only within one family, never Synapse, never stretched. Not on every page.

### 5. Templates: qual usar (15 min)
| I need to… | Use |
|---|---|
| Present to partners or the public | Brand deck |
| Present a formal result or to a board | Formal deck |
| Send an official letter or memo | Letterhead (pick the mode) |
| Issue a certificate | Certificate (formal) or certificate-brand (simpler events) |
| Invite to an event | Invitation |
| Send a newsletter or notice | E-mail (Boletim, Comunicado) |
| Post on social | Social templates |
| Make a badge | Badges |
| Decorate a screen or wall | Wallpapers, posters |
Controlled documents: type and code top right. E-mails: date in the header, never a code; titles never bold.

### 6. Redação e detalhes (10 min)
Sentence case; uppercase only for labels. No middle dots, no em dashes as separators, no emoji. 1.284 and 0,94; codes like `NRO-REL-2026-014`. Left-aligned, never justified.

### Practical exercise (15 min)
Three broken pieces built from real templates; participants list and fix the errors:
1. **Slide**: two colour families, Synapse background, bold serif title, logo on a content slide, middle dots in the footer.
2. **E-mail**: black logo on a family-coloured header, bold title, a code instead of the date, justified text.
3. **Certificate**: Plex Mono for the date, stretched logo, functional green as accent, a body title repeating the header.

## Cheat sheet: ten rules
1. Operational mode by default; executive only for formal pieces.
2. Primary + neutral first; Synapse is a spark, never a field.
3. One colour family per piece.
4. Only Cortex in glows, gradients and glass.
5. Plex Mono only for codes and data.
6. Never bold for hierarchy; use a lighter tone of the same family.
7. Logo: black, white or one family's tone; never stretched, never Synapse; not on every page.
8. No middle dots, no em dashes as separators, no emoji.
9. Left-aligned, sentence case, Brazilian number format.
10. Start from a template, never from a blank page.

## Quiz topics (at least one question each)
Mode for a given piece; Synapse use; mixing families; logo recolour; Plex Mono use; bold hierarchy; functional set in a document; middle dots; e-mail header field; controlled-document header; which deck; no pill shapes.

## Success criteria
After the session a participant can produce a slide, an e-mail and a memo from the templates with no cheat-sheet violations.
